# Data Files — Notes & Exceptions

This document tracks notable data file situations that deviate from normal expectations.

## Large Committed Files

### `data/2022-presidential-results/MMV_NACIONAL_PRESIDENTE_2022_1v.csv`

**Size**: ~135 MB (uncompressed)  
**Tracked in git**: Yes (also has a `.csv.gz` counterpart)  
**Why**: The compressed `.gz` version is the canonical source (5.6 MB). The uncompressed `.csv` is committed because the decompress-before-use workflow (`gunzip ...*.csv.gz`) is documented in `AGENTS.md` §10 and `README.md` Prerequisites.  
**`.gitignore` exception**: Line 27 of `.gitignore` matches `data/2022-presidential-results/MMV_NACIONAL_PRESIDENTE_2022_*v.csv` — but the file was committed before the rule was added. The rule prevents future re-commits.  
**Action**: To remove from history would require `git filter-repo` and a force-push to all branches — not worth the disruption for publicly available data. The file remains as-is.

## Generated Artifacts

- `data/processed/municipal_feature_matrix.{csv,parquet}` — auto-generated by `make fundamentals`. Committed for reproducibility but regenerable.
- `data/fundamentals/*.csv` — built-in component matrices. Some are stubs (e.g., `socioeconomic.csv` has only 3 rows, `risk_factors.csv` has 10).
- `data/fundamentals/COVERAGE.md` — auto-generated by report pipeline, gitignored.
