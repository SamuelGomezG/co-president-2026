# data/

**Purpose**: Data files for the co-president-2026 project. Raw external data is not tracked in git — see `docs/data/` for download instructions.
**Category**: data

| `2026-polls/` | CNE poll microdata ZIP bundles | ❌ (external) |

| `raw/` | Raw API downloads | ❌ |
| (many others) | Placeholder directories | ❌ |
